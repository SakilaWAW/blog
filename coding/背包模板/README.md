# 背包问题模板（JavaScript）

适用于常见的背包问题：
- 0-1 背包（每个物品最多选一次）
- 完全背包（物品可无限次选）
- 多重背包（物品有数量上限）
- 二维 0-1 背包（两个容量约束）
- 分组背包（每组最多选一件）
- 子集和 / 可行性布尔 DP（是否能凑出目标和）
- 路径回溯（从 DP 中恢复具体选取方案）

## 使用方式
- 在 Node.js 中可用 `require` 引入各模板文件：
  ```js
  const { knapsack01 } = require('./01_0-1背包');
  const { completeKnapsack } = require('./02_完全背包');
  ```
- 每个文件结尾均导出对应方法，函数签名在文件内注释说明。

## 速查：循环顺序与转移
- 0-1 背包：`for items -> for j = W..w`（倒序，防重复选）
- 完全背包：`for items -> for j = w..W`（正序，允许重复选）
- 多重背包：先做“倍增拆分”，转 0-1 背包；或用单调队列优化（一维）
- 二维 0-1 背包：两个容量都倒序更新 `i = C1..w1, j = C2..w2`
- 分组背包：对每组用旧 dp 计算候选，再整体更新为新 dp
- 子集和（布尔）：`dp[0]=true`，0-1 用倒序，完全用正序

## 提示与常见坑
- 正序/倒序的选择是关键，决定是否允许重复选取同一物品。
- 空间压缩到一维时，更新顺序必须正确，否则会“串改”已更新值。
- 回溯选取方案时，常用二维 `dp[i][j]` 对比转移来判断是否选中第 `i` 件。
- 二维或更高维背包要注意初始化和边界判断（只能在容量足够时转移）。
